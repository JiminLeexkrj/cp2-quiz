# 컴프2 이해 확인 100제

컴퓨터프로그래밍 2 학습 가이드의 **이해 확인 100문제**를 한 문제씩 풀고, 바로 정답과 해설을 확인하는 퀴즈 사이트입니다.

- 개념 30문제 (001–030), 코드 해석·수정 30문제 (031–060), 실전 구현 40문제 (061–100)
- 문제마다 **정답과 해설 보기** → **맞았다 / 헷갈렸다 / 틀렸다** 자가 채점
- 031번부터는 **브라우저 안 Python 실행기**([Pyodide](https://pyodide.org)) 제공: 문제 코드 불러오기, 예시 입력(stdin), 해설 코드 바로 실행, 무한 반복 자동 중단(8초)
- 채점 결과·내 답·작성한 코드는 브라우저(localStorage)에 자동 저장
- 필터: 영역별 / 안 푼 문제 / 복습 필요(헷갈림·틀림) / 북마크
- 다크 모드, 모바일 화면 지원

## 단축키

| 키 | 동작 |
|---|---|
| `Space` | 정답과 해설 보기 / 접기 |
| `1` `2` `3` | 맞았다 / 헷갈렸다 / 틀렸다 (해설을 연 뒤) |
| `←` `→` | 이전 / 다음 문제 |
| `B` | 북마크 |
| `Ctrl` + `Enter` | 실행기에서 코드 실행 |

## 구조

```
content/questions.md   문제 원문 (사이트용으로 일부 다듬은 사본)
content/answers.md     정답과 해설
build.mjs              content/*.md → assets/data.js (마크다운을 HTML로 미리 렌더링)
assets/app.js          화면·채점·저장
assets/runner.js       Pyodide Web Worker 실행기
assets/style.css
index.html
```

문제나 해설을 고친 뒤에는 다시 빌드합니다.

```bash
npm install
npm run build
```

`content/questions.md`에서 문제 아래 `<!-- stdin: ... -->`는 실행기의 예시 입력(`\n`은 줄바꿈), `<!-- note: ... -->`는 사이트에 표시되는 “수정됨” 안내입니다.

## 원본에서 다듬은 부분

원래 문제집을 그대로 옮기되, 퀴즈로 풀 때 애매했던 곳만 손봤습니다.

- **029** `date`가 어디서 왔는지 알 수 있도록 import 전제를 추가
- **030** “설치 화면·그래프 화면·홍보 화면”이 강의 자료 chap01의 어느 그림인지 밝히고 세 문항으로 분리
- **060** 가리키는 대상이 없던 “위 셀”을 실제 코드가 있는 “셀 A”로 다시 씀 (해설도 1)·2)로 정리)
- **073 · 075 · 078 · 082 · 096** 입력 형식(한 줄 공백 구분 등)을 명시
- **089 · 092 · 094** 예시 출력을 실제 Python 리스트 출력 형태(`['a', 'b']`)로 맞춤
- 해설 **002 · 007 · 019 · 029 · 060 · 074**를 더 정확하게 보완 (예: SyntaxError가 있으면 앞줄도 실행되지 않음, 실수 오차 주의)
- 숫자·영문이 한글에 붙어 있던 문장의 띄어쓰기 정리

031–100번의 모든 코드와 정답 코드는 Python 3.14에서 실행해 해설의 결과와 일치함을 확인했습니다.
